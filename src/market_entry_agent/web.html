理解智能体怎样工作

一次有边界的研究

任务 → 自主选择工具 → 读取证据 → 形成判断 → 保存成果。工具执行逐步记录，失败任务可以从已保存的进度继续。

可用工具：国区指数与分项比较、研究目录与行动计划合同、检索证据、读取原始记录、回看同一任务的成果、列出信息源、刷新订阅源、搜索公开关键词、抓取已许可网页、完成报告。

模型每轮自行选择工具，页面任务最多 18 步；命令行任务可配置 4–30 步和 10–600 秒预算。没有可用证据时，应交付缺口与后续观察建议。

两个项目如何互通

GeoRisk Agent 与 Market Entry Agent 使用相同的 field-evidence/v1 格式，可交换公开证据包，或显式连接同一公共证据数据库。企业背景、任务、历史结果和提醒保存在各自私有工作空间。
