# 在一个项目里把研究接下去

项目页新增研究档案，汇集本项目最近保存的报告、仍未解决的问题、来源、假设与判断，以及知识库和持续关注数量。资料保持原来的项目范围；打开档案不刷新网络，不调用模型，也不替用户调整选择。较早任务不会因为其他项目的新任务而被挤出本项目列表。

## 地缘政治：从议题到变化

围绕国际组织、区域问题或事件建立项目。导入声明、笔记和研究资料后，在研究工作台选中知识库，选择专题研究或事件跟踪。报告保存后，在项目持续跟踪中打开同一项目，即可看到已有解释、未解决问题与来源。需要继续时点“继续研究这个项目”，提出本次问题；原有任务和判断仍可回看。任务不涉及企业时，无需虚构企业背景。

## 企业出海：从方案到条件

在同一项目中保存企业条件、市场与进入方式、交易责任、关键前提及报价。选择知识库开展市场比较或交易研究，报告与后续问题一并保留。新报价、政策材料或客户条件出现后，再回到本项目研究。口头意向、拟议分工和已经确认的责任分别说明；规则覆盖范围、例外与生效条件分别判断。

## 更容易找到材料

私有知识库增加公共机构和术语的有限中英文别名匹配，如欧盟/EU、联合国/United Nations、CBAM 的中英文名称。它是本地词项扩展，不是向量语义检索，也不会产生新的公开查询。中英文混排和全角字母可检索；旧文档无需迁移就能使用新的匹配方式。

新导入文件按段落或行边界分片，并保留相邻重叠和精确文字位置，Markdown 记录可取得的章节名。搜索结果优先展示匹配位置，可展开阅读片段。在页面设置发布日期范围时，默认不把日期未知的材料混入范围；可以明确勾选包含未知日期。导入时间不会替代发布日期。

已保存报告中的“阅读报告引用的文件片段”读取的是该任务固定的文档版本。文件替换后仍可阅读原引用；删除文件则撤销继续读取原件和片段的权限。已经保存的报告和摘录仍有各自的保留规则。

## 选择公开来源

`examples/public-source-pack.json` 是可选择登记的官方页面配置。地缘政治提供 IMO 红海专题和一份历史事件声明；出海提供欧盟 CBAM 页面和英国 CPTPP 资料集合。页面类型、国区和主题由操作者配置，不代表覆盖所有国际问题或企业。只有显式登记后才供取材；登记不启动监测。

在独立工作空间执行 `sources examples/public-source-pack.json`，再按来源 ID 抓取或让有权限的研究任务取材。CLI 的完整前缀分别为 `georisk-agent` 或 `market-entry-agent`；Windows 可通过虚拟环境 Python 的 `-m` 入口调用。专题页面可能只有更新记录而没有单一发布日期，这时保留日期未知；网页正文也不能代替其链接法规或报告全文。

## 接口

- `manage desk overview --project PROJECT` / `GET /api/desk/overview?project_id=PROJECT` 读取本项目研究档案。
- 知识搜索管理命令的数据可以带 `filters`，支持 `countries`、`topics`、`published_after`、`published_before` 与布尔 `include_undated`。HTTP 搜索通过 POST 传入这些结构化字段。
- `knowledge cited` 需要 `project_id`、`run_id` 和该报告实际引用的文档证据 `id`；产品、项目、引用与冻结版本均在服务端检查。

上述操作保留原有认证、Host 与 Origin 检查。客户之间仍须使用独立工作空间，项目筛选不等于多租户认证。
