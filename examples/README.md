# Examples

`demo-evidence.json` and `mission.json` are fictional fixtures. `public-data-mission.json` uses the bundled public World Bank observations and published reference calculation. Run the demo without credentials; model research requires your configured provider. Keep private instructions, data and outputs outside the repository.

`report-cases.json` supplies three historical decision cases with attributed public summaries and fictional enterprise conditions. `python scripts/evaluate_cases.py --list` does not call a model; `--case ID --output PRIVATE_EMPTY_DIRECTORY` explicitly calls your configured provider. Keep unchanged reports and runtime receipts outside this repository. Sources are curated summaries, not full-page downloads or complete market coverage.
